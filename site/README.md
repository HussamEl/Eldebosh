# site/

**مخرجات بناء — ليست شيفرة مصدرية.**

هذا ناتج `astro build`. أي بناء جديد من مصدر Astro سيمسح كل تعديل هنا، لذا:

- التعديلات الحالية موثّقة بصيغتها الأصلية في [`../docs/03-fixes-log.md`](../docs/03-fixes-log.md).
- طريقة الرفع وقائمة الفحص في [`../docs/05-deployment.md`](../docs/05-deployment.md).
- لتجربته محليًا: `npm run serve` ثم `npm run verify`.

ارفع **محتويات** هذا المجلد إلى جذر النطاق، مع `.htaccess`.
