# Eldebosh

مستودع الموقع والهوية البصرية.

```
site/    الموقع جاهز للرفع — ارفع محتوياته إلى جذر الاستضافة (مع .htaccess)
brand/   حزمة الهوية: SVG، PNG، أيقونات، مقاسات سوشال، ملفات تريث PDF، ومولّداتها في src/
FIXES.md ما تغيّر ولماذا — الألوان، أعطال الصور، وتركيب الشعار
```

## الموقع

مخرجات بناء Astro (dist) وليست الشيفرة المصدرية. أي `npm run build` من المصدر سيمسح هذه
التعديلات، لذا انقلها إلى المصدر أولاً — التفاصيل كاملة في [`FIXES.md`](FIXES.md).

**ما أُصلح:**

- الألوان صارت الكحلي/السماوي بدل الليموني، مطابقة للتصميم المعتمد.
- عارض صور المنتجات: كان يُقصّ داخل البطاقة عند كل نقرة على سطح المكتب — لأن `.viewer`
  عنصر `position:fixed` داخل بطاقة عليها `transform` عند المرور، فتصبح البطاقة
  containing block له ويقصّه `overflow:hidden`. الآن يُنقل إلى `<body>` عند التحميل.
- تجميد التلاشي عند المرور كان يترك صورتين نصف شفافتين فوق بعضهما.
- الشريط الأزرق أسفل الصور كان يختفي بسبب تنازع قاعدتين على نفس `:after`.
- النافذة تُغلق الآن بـEscape والخلفية وزر ×، مع حصر التركيز وقفل تمرير الخلفية،
  دون قفزات في الصفحة ولا تلويث لتاريخ التصفح. `:target` باقٍ كخطة بديلة بدون JS.

## الهوية

حرف **E** من ثلاثة أعمدة مستديرة، أوسطها سماوي — نفس «شريط الشحن» في تصميم الموقع.
الكلمة مسارات متجهية مستخرجة من خط Inter Tight عبر HarfBuzz، فلا تحتاج تثبيت خط.

`brand/src/` يحتوي المولّدات: `python3 build_logo.py && python3 assets.py && python3 print.py`
ثم `node render.mjs` و`node print.mjs` يعيدان بناء كل ملف في الحزمة.

**بيانات كرت العمل نموذجية** — استبدلها قبل الطبع.
