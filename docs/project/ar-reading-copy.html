وثائق المشروع الحاكمة

أربع وثائق تحكم العمل بين حسام وثلاثة مساعدين. هذه نسخة قراءة بالعربية — النسخة الإنجليزية في المستودع هي المرجع الذي يقرأه المساعدون.

لماذا الإنجليزية هي المرجع؟ المساعدون يقرأونها أسرع وأدق، والفحص الآلي يتحقق من أرقام إصداراتها. وهذه الصفحة تُعاد كتابتها كلما تغيّرت النسخة الإنجليزية — الرقم أعلى الصفحة يخبرك إن كانت متأخرة. المصدر: docs/project/ في المستودع.

المستودع مصدر الحقيقة — لا الحزم

لا ترسل حزمة مشروع. صف التعديل، وينفّذه كلاودي كود في المستودع.

حزمة أقدم من المستودع تُعيد إصلاحات كانت مدفوعة فعلًا. والمستودع عام، فمن يصل إلى الإنترنت يقرأ منه أحدث نسخة مباشرة.

المعاينة قبل الحزمة

عند أي طلب تعديل بصري — لون، مسافة، خط، تخطيط:

npm run preview:file

يولّد ملفًا واحدًا مكتفيًا بذاته يُفتح على الجوال وفيه كل الصفحات تعمل. أرسل ملف المعاينة وحده. دورة «عدّل ← احزم ← ارفع ← انشر ← انتظر» تهدر أيامًا.

اقتصاد الجلسة

  • محادثة واحدة لكل مرحلة. عند انتهائها: حدّث الوثائق ثم ابدأ محادثة جديدة.
  • لا ترفق ملفًا إلا عند الحاجة الفعلية — استخدم الرموز مثل P-04-1.
  • لا تعد إرسال ما لم يتغيّر.

لا اختلاق

ممنوع اختراع مواصفات أو أسعار أو تقييمات أو شهادات أو نتائج اختبار. كل معلومة تعود إلى مصدر موثق؛ وإلا فاكتب «يحتاج تحققًا» ولا تنشر. ويشمل هذا المعلومات التقنية: إن لم تكن متأكدًا من كيفية عمل أداة، تحقق قبل الشرح.

ثلاث قواعد أخرى

  • لا محتوى ضعيف — ولا رابط يقود إلى صفحة فارغة.
  • لا أسرار في أي ملف، بما في ذلك الوثائق.
  • الالتزام السويدي — الإفصاح التجاري ظاهر أعلى كل صفحة تجارية لا في الفوتر فقط.

قواعد هندسية لا تُخترق

كل بند وقع فعلًا وكلّف وقتًا.

  1. قارن المصدر لا الناتج.تطابق الناتج لا يثبت إلا ما يمر بمسار البناء. ما هو خارجه — لوحة التحرير، الأيقونات، الشعار المستقل — يحتاج فحصًا خاصًا.
  2. site/ يُبنى ولا يُحرَّر.أي تعديل عليه يُمحى عند أول npm run build.
  3. transform يقصّ position:fixed.عنصر يحمل تحويلًا يصبح الحاوية لأي عنصر مثبَّت بداخله. الحل: نقله إلى body.
  4. display:flex يتغلب على hidden.كل عنصر يُخفى برمجيًا يحتاج [hidden]{display:none!important}.
  5. مفتاح ترجمة ناقص يُنتج undefined صامتًا.astro build لا يفحص الأنواع، لذلك t() يرمي استثناءً عند أي مفتاح مفقود.
  6. كروم يتجاهل focus({preventScroll})داخل حاوية قابلة للتمرير. القفل الصحيح: position:fixed على body مع حفظ الإزاحة.
  7. SVG يقصّ rx إلى نصف العرض ويُبقي ry.القاعدة: rx = min(width, height) / 2.
  8. الاستبدال النصي يصيب أول تطابق لا المقصود.شغّل الفحص بعد أي تعديل آلي.
  9. ويندوز.استخدم fileURLToPath لا .pathname.
  10. لا اسم لون في اسم متغيّر.--brand لا --pine. ولا كتلتان داكنتان متلاصقتان.

النشر — كيف يعمل

main → GitHub Actions يبني ويفحص → فرع deploy → Hostinger تسحب → الموقع

فرع deploy يحمل الموقع المبني وحده في الجذر، ولا يُدفع إليه يدويًا — Actions يحدّثه عند كل دفعة إلى main.

لماذا هذا الشكل؟

الرفع عبر FTP من غيتهب كان يسقط لأن الاستضافة تحجب خوادمه. والحجب على اتجاه الدخول وحده — والاستضافة تخرج بلا مانع. فعُكس الاتجاه: هي تسحب بدل أن يُدفع إليها. والاستضافة لم تتغيّر.

⚠️ لوحة التحرير تكتب في المستودع لا في الموقع.

التغيير يصل خلال دقائق عبر السلسلة أعلاه — لا فورًا. والسحب اليدوي متاح: hPanel ← Git ← Redeploy.
