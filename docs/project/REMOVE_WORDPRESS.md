# إزالة ووردبريس واستعادة الموقع الثابت — v1.0

> ووردبريس صار يتحكم بالدومين. هذا الدليل يعيد الموقع كما كان، بلا فقدان أي تصميم أو محتوى.

---

## ١. اطمئن أولاً

**لن تخسر شيئاً.**

كل التصميم والمحتوى موجود في مجلد المشروع على جهازك، لا على الخادم. ووردبريس لم يمس المشروع إطلاقاً — هو مجرد ملفات وُضعت فوق الموقع القديم على الخادم.

**والموقع الجاهز موجود في مجلد `site` داخل هذه الحزمة.** رفعه يعيد كل شيء.

---

## ٢. لماذا صار ووردبريس يتحكم

عند تثبيته أضاف إلى المجلد العام:

```
index.php
wp-admin/
wp-includes/
wp-content/
wp-config.php
.htaccess
```

**الملفان الحاسمان:**

`index.php` يجعل ووردبريس هو نقطة الدخول بدل `index.html`.

`.htaccess` يحوّل **كل** طلب إلى ووردبريس، حتى الصفحات التي لا يملكها. لهذا لا تعمل مساراتك القديمة.

---

## ٣. الحذف — بالترتيب

### قبل أي شيء: خذ نسخة احتياطية

من لوحة Hostinger:

```
Files ← Backups
```

اطلب نسخة كاملة وانتظر اكتمالها. **دقيقتان تحميانك من ساعات.**

### الخطوة الأولى: احذف قاعدة البيانات

من لوحة Hostinger:

```
Databases ← MySQL Databases
```

احذف قاعدة البيانات التي أنشأها ووردبريس، والمستخدم المرتبط بها.

**لماذا أولاً؟** لأن حذف الملفات قبلها يترك قاعدة بيانات يتيمة تستهلك من حصتك.

### الخطوة الثانية: احذف كل الملفات

من مدير الملفات:

```
/public_html/
```

**حدّد كل شيء بداخله واحذفه.** كل شيء — الملفات المخفية أيضاً.

⚠️ **تأكد من إظهار الملفات المخفية** قبل الحذف، وإلا سيبقى `.htaccess` ويستمر في تحويل كل الطلبات إلى صفحة خطأ.

في مدير ملفات Hostinger:

```
Settings ← Show hidden files
```

### الخطوة الثالثة: تحقق أن المجلد فارغ

أعد تحميل الصفحة. **يجب ألا يبقى ملف واحد.**

---

## ٤. أعد رفع الموقع

ارفع **محتويات** مجلد `site` — المحتويات نفسها لا المجلد.

بعدها يجب أن ترى في `/public_html/` هذه العناصر فقط:

```
index.html
sv/
en/
admin/
_astro/
fonts/
uploads/
pagefind/
favicon.svg
logo.svg
og-default.png
qr-card.png
qr-eldebosh.png
robots.txt
sitemap-index.xml
sitemap-0.xml
```

**أي شيء آخر بقايا ووردبريس.**

---

## ٥. تحقق من النتيجة

افتح الموقع بـ:

```
Ctrl + Shift + R
```

ثم اضغط بالزر الأيمن واختر `View page source`، وابحث عن:

```
eldebosh-build
```

بجانبه تاريخ البناء. **إن كان تاريخ اليوم، فكل شيء سليم.**

---

## ٦. لا تعد تثبيت ووردبريس

طالما بقيت على الموقع الثابت.

**تشغيلهما معاً على نفس المجلد مستحيل** — كلاهما يريد أن يكون نقطة الدخول، وأحدهما سيغلب الآخر دائماً.

**إن أردت تجربة ووردبريس مستقبلاً**، ثبّته على نطاق فرعي منفصل مثل:

```
wp.eldebosh.com
```

فلا يمس الموقع الأصلي إطلاقاً.
