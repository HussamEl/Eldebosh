# eldebosh.com — v1.0

موقع محتوى سويدي مبني بـ Astro، يُنشر ثابتاً على Hostinger.

## للتحرير اليومي
افتح `https://eldebosh.com/admin` في المتصفح. اكتب، ارفع الصور، اضغط نشر.
الموقع يُبنى وينشر تلقائياً خلال دقيقة تقريباً. **لا حاجة لفتح أي ملف.**

## للتشغيل المحلي (لأداة التنفيذ)
```
npm install
npm run dev      # http://localhost:4321
npm run check    # فحص القواعد الملزمة
npm run build    # فحص + بناء + فهرسة البحث
```

## تسلّم المشروع لأول مرة؟

**اقرأ [`HANDOVER.md`](HANDOVER.md) وحدها.** فيها أين وصل المشروع، وما الموجود
على غيتهب، وكيف يعمل النشر، وكيف يجري التواصل بين الأطراف. عشر دقائق تكفي.

## الملفات المرجعية
- `CLAUDE.md` — القواعد الملزمة والقرارات المغلقة.
- `SPEC.md` — المواصفات التقنية وبنية الروابط.
- `HANDOVER.md` — **التسليم: أين وصلنا وكيف يعمل كل شيء.**
- `TASKS.md` — خطة العمل بالتسلسل مع معايير القبول.
- `KEYWORD_MAP.md` — خريطة الكلمات المفتاحية و33 صفحة مستهدفة.
- `HANDS_ON_GUIDE.md` — قواعد التجربة الفعلية وبروتوكول التصوير.
- `AMAZON_PLAN.md` — خطة الربط بأمازون وطابور المنتجات المملوكة.
- `PUBLISH_CHECKLIST.md` — الخطوات الخمس المتبقية لنشر أول صفحة تبيع.
- `STATE.md` — **لوحة الحالة** (تُحسب آلياً). ابدأ منها دائماً.
- `DECISIONS.md` — سجل القرارات المغلقة وأسبابها.
- `ISSUES.md` — المشاكل القائمة بأدلتها.
- `CHANGELOG.md` — سجل التغييرات وبروتوكول التسليم.
- `RISKS.md` — سجل المخاطر.
- `PHOTO_NAMING.md` — **تسمية الصور والتبديل التلقائي.**
- `REFERENCE_SYSTEM.md` — **نظام الرموز المرجعية.** بدل إعادة رفع الصور.
- `ASSETS.md` — فهرس الأصول (يُولَّد آلياً).
- `UPLOAD.md` — **قواعد الرفع إلى الخادم.** اقرأه قبل أي رفع يدوي.
- `REMOVE_WORDPRESS.md` — إزالة ووردبريس واستعادة الموقع الثابت.
- `DEPLOY_FIX.md` — تشخيص النشر التلقائي وحلوله.
- `SERVER_FILES.md` — قائمة المجلدات الصحيحة بعد الرفع (تُولَّد آلياً).

## معاينة محلية على الجوال
```
npm run preview:file
```
يولّد `eldebosh-preview.html` — ملف واحد مكتفٍ بذاته فيه كل الأنماط والخطوط والصور.
انقله إلى الجوال وافتحه من مدير الملفات. يعمل بلا إنترنت وبلا خادم.

## رمز المسح للقاءات الشخصية
`public/qr-card.png` — بطاقة جاهزة للطباعة.
`public/qr-eldebosh.svg` — الرمز وحده، يكبر بلا فقدان جودة.
الرمز يقود إلى `/sv/` مع وسوم تتبع تميّز الزيارات القادمة من اللقاءات الشخصية.

## لماذا يفشل البناء أحياناً؟
`npm run build` يشغّل فحصاً آلياً يمنع: منتجاً بلا مصدر، رابط أفلييت داخل نص مقال، صفحة لا تربط بصفحة حل، أو حقل سعر ثابت. **الرسالة تشرح السبب — أصلح السبب، لا الفحص.**
