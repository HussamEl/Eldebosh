## 1. السؤال الحاسم

**متى قدّمت طلب أمازون أسوسييتس؟**

المهلة **١٨٠ يوماً من تاريخ التقديم**، لا من تاريخ إطلاق الموقع. وإن انتهت بلا ثلاث مبيعات، يُغلق الحساب **ولا يمكن استرجاع المعرّف**.

المعرّف الحالي:

```
electro066-21
```

**أخبرني بالتاريخ، وأعيد ضبط الجدول الزمني على أساسه.**

## 2. ما تغيّر في الترتيب

**الترتيب القديم:** كل المحتوى أولاً، ثم الأفلييت.
**الترتيب الجديد:** أقصر طريق إلى صفحة تبيع.

| القديم | الجديد |
|---|---|
| ٣٣ صفحة ثم الأفلييت | ٥ صفحات تبيع، ثم التوسع |
| منتجات غير مملوكة | **مشترياتك أنت** |
| صور من الواجهة البرمجية | **صورك أنت** |

**السبب:** الواجهة البرمجية لصور أمازون تحتاج مبيعات أولاً. صورك تحل المشكلة اليوم.

## 3. الربط التقني — منجز

النظام الآن يبني روابط أمازون **تلقائياً** من حقل واحد.

**أنت تدخل:**

```
asin: B0XXXXXXXX
```

**والنظام يبني:**

```
https://www.amazon.se/dp/B0XXXXXXXX?tag=electro066-21&linkCode=ll1&language=sv_SE
```

**فوائد هذا القرار:**

- استحالة نسيان الوسم — سبب شائع لضياع العمولات.
- تغيير الوسم مستقبلاً = تعديل سطر واحد ينعكس على كل الصفحات.
- الفحص الآلي يرفض ASIN بصيغة خاطئة، ويرفض رابط أمازون ملصوقاً يدوياً.

**كيف تجد ASIN؟** من رابط المنتج، الجزء الذي يلي `/dp/` — عشر خانات.

## 5. ما ينقص كل ملف

خمسة حقول فارغة، وأربعة منها لا يستطيع أحد ملأها غيرك:

```
asin               من رابط المنتج
source_url         رابط صفحة المنتج
own_photos         صورك الأربع
hands_on           ملاحظاتك من الاستخدام
hands_on_limits    ما لم تجربه
```

ثم:

```
verified: true     بعد اكتمال asin و source_url
tested: true       بعد اكتمال الصور والملاحظات والحدود
```

**تنبيه:** المنتج بـ`verified: false` لا يظهر في أي صفحة. هذا مقصود.

## 6. الجدول التنفيذي

### الأسبوع الأول — أقصر طريق إلى صفحة تبيع

**اليوم ١–٢**
افتح صفحات المنتجات الأربعة للبطاريات على أمازون، وانسخ ASIN و الرابط لكل واحد.

**اليوم ٣**
جلسة تصوير واحدة: أربع صور لكل منتج. أربعة منتجات = ١٦ صورة في ساعة.

**اليوم ٤**
أدخل البيانات من اللوحة، وفعّل `verified` و`tested`.

**اليوم ٥–٦**
اكتب صفحة الحل:

```
batteriet-tar-slut
```

**اليوم ٧**
اكتب الدليل:

```
basta-powerbank-2026
```

بأربعة ترشيحات من منتجاتك، ثم انشر الاثنين.

**النتيجة:** صفحتان تحملان روابط أمازون تعمل.

### الأسبوع الثاني

Search Console وأداة التحليلات. **بلا فهرسة لا زيارات، وبلا زيارات لا مبيعات.**
ثم عنقود الكابلات بنفس الطريقة.

### الأسبوع الثالث فصاعداً

عنقود الحوامل، ثم التوسع حسب خريطة الكلمات.

## 7. تحذيرات تفقدك الحساب

| ❌ ممنوع | لماذا |
|---|---|
| الشراء عبر روابطك | أمازون تطابق العنوان والبطاقة والشبكة — إغلاق فوري |
| طلب شراء من العائلة | يُكتشف ويُعاقب بنفس القسوة |
| نسخ صور المتجر يدوياً | سبب معروف لإغلاق الحسابات |
| كتابة سعر ثابت في الصفحة | مخالف لشروط البرنامج |
| إعلانات مدفوعة تقود إلى أمازون | لا تؤهل للعمولة |

**نص الإفصاح الإلزامي** مضاف بالفعل أعلى كل صفحة تجارية وفي الفوتر، بالسويدية والإنجليزية.

## 8. عمل ينتظرك خارج الشاشة

**سياسة الخصوصية** لا تزال مسوّدة، وهي **شرط للقبول**. أكملها هذا الأسبوع.

**بيانات التقييمات** ظاهرة في لقطاتك (الدرجة وعدد التقييمات لكل منتج). أدخلها في حقل التقييم الخارجي مع الرابط وتاريخ الاطلاع حين تفتح صفحات المنتجات — تظهر موثقة في البطاقة.
