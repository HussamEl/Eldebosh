## ١. الأطراف

| 👤 | **حسام** | مدير المشروع: القرار النهائي · المنتجات والتصوير · المراجعة الأخيرة للسويدية | ليس مبرمجاً |
| 🛠️ | **كلاودي كود** | الكود والمعمارية · **كتابة المحتوى** (السويدية والمصادر) · الفحوص والنشر | لا يقرّر عن حسام · لا يدقّق عمله بنفسه |

وجيميناي يراجع، وحسام يقرّر.

**حسام هو القناة الوحيدة** بين كلاودي كود وجيميناي.

## ٢. التشاور قبل التنفيذ

1. **كل مهمة تبدأ بتشاور، لا بتعديل.** لا يُمسّ ملف قبل أن يوافق حسام.
2. **الرد الأول تحليل:** كيف أرى الموقف، وما الذي سيتأثر، ورأيي المهني، وتوصيتي
   مع البديل إن وُجد وما تكلّفه. **ثم أتوقف وأنتظر القرار.**
3. **الاستثناء الوحيد — الإصلاح الفوري:** إن تعطّل البناء أو الفحص أو النشر
   على غيتهب، أُصلحه فوراً بلا انتظار، وأبلغ بما فعلته في رسالتي التالية.
   والسبب: النشر المعطّل يوقف كل ما يحفظه حسام من لوحة التحرير.
4. **وما ليس قراراً لا يُعرض كقرار:** أوامر `git` والفروع وإصدارات الحزم
   والتنسيق يحسمها المنفّذ.

**قرار حسام دائماً:** ما يراه الزائر · المحتوى قبل نشره · التصميم · المال ·
حساب أمازون · البنية والروابط وهيكل البيانات · أي سكربت جديد.

## ٣. شكل كل رسالة من كلاودي كود

**تبدأ بسطر الترقيم** وتنتهي بأربعة أشياء بهذا الترتيب:

1. **لوحة الأطراف.**
2. **ملخّص الفروقات** — ما تغيّر في المستودع، في أسطر قليلة. «لا تغيير» إن لم يتغيّر شيء.
3. **روابط خام** لكل ملف أُنشئ أو عُدّل، بهذه الصيغة، ليقرأها جيميناي مباشرة:

```
https://raw.githubusercontent.com/HussamEl/Eldebosh/main/<مسار الملف>
```

4. **ثلاثة ردود جاهزة للنسخ**، كلٌّ في كتلة كود مستقلة:
   - **نص الموافقة** — يمنح الضوء الأخضر للتنفيذ.
   - **نص لجيميناي** — يلخّص المقترح أو التحديث، مع الروابط الخام.
   - **نص للاستفسار** — يطلب توضيح خطوة.

**وصفحات الرابط الخام تتأخر حتى خمس دقائق بعد الدفع** بسبب التخزين المؤقت في
غيتهب. إن رأى جيميناي نسخة قديمة فليُعِد الفتح بعد دقائق.

## ٤. ترقيم الرسائل

```
EB-004 · كلاودي كود · 2026-09-23 21:10 · رداً على EB-003
```

| الحقل | القاعدة |
|---|---|
| الرقم | **عدّاد واحد لكل الأطراف**، ثلاث خانات، بلا فجوات |
| الاسم | حسام · كلاودي كود · جيميناي |
| الوقت | **بتوقيت كارلستاد**، يُقرأ من الساعة ولا يُقدَّر |
| رداً على | الرسالة المجاب عنها، أو «موضوع جديد» |

- رسالة حسام بلا رقم تأخذ الرقم التالي عند تسجيلها.
- **السجل:** `docs/project/LOG.md`، ويحدّثه كلاودي كود. والرقم الحرّ والوقت الصحيح:

```
npm run check:docs
```

معنيّ · `✅` أنجز. **كل الأطراف تظهر في كل مرة.**

## ٥. المستودع هو الذاكرة — والمزامنة

المحادثات لا تُحفظ. **ما ليس في المستودع غير موجود.** والمستودع عام.

**جيميناي في أول كل محادثة جديدة** يقرأ هذه الروابط الأربعة:

```
https://raw.githubusercontent.com/HussamEl/Eldebosh/main/docs/project/INSTRUCTIONS.md
https://raw.githubusercontent.com/HussamEl/Eldebosh/main/docs/RULES.md
https://raw.githubusercontent.com/HussamEl/Eldebosh/main/docs/project/STATE.md
https://raw.githubusercontent.com/HussamEl/Eldebosh/main/docs/project/TASKS.md
```

**وبين المحادثات** يبقى محدّثاً من ملخّص الفروقات والروابط الخام في آخر كل
رسالة من كلاودي كود.

**الأرقام تُقرأ من `STATE.md` ولا تُكتب من الذاكرة.**

## ٦. الاقتصاد في التوكينز

1. **جلسة جديدة لكل مهمة** عند كلاودي كود. الجلسة تعرف المشروع من المستودع
   وحده، فلا يضيع شيء. والجلسة الطويلة تُعيد قراءة كل تاريخها مع كل رسالة.
2. **القراءة المستهدفة:** يُفتح الملف المطلوب تعديله فقط، ولا يُقرأ المستودع
   كله إلا بطلب صريح.
3. **لا يُلصق لكلاودي كود نصّ موجود في المستودع** — يكفي اسم الملف أو رمز
   الصورة مثل `P-03-1`.
4. **الطلبات الصغيرة تُجمع** في رسالة واحدة.

## ٧. المحتوى والمصادر

- كلاودي كود يكتب المحتوى في ملفاته مباشرة، بمرحلة `written`، ولا يصير
  `published` إلا بعد مراجعة جيميناي وموافقة حسام.
- **جيميناي يصرّح في أول سطر من كل مراجعة هل فتح المصادر فعلاً أم لا.**
  و«لا مصدر» جواب مقبول؛ الحكم من الذاكرة ليس مقبولاً.
- القواعد وأنواع الصفحات والمصطلحات السويدية:

```
docs/RULES.md
docs/CONTENT.md
```

## ٨. كيف نخاطب حسام

- **ليس مبرمجاً:** لغة عملية، ولا أوامر طرفية إلا للضرورة القصوى.
- **يقرأ بالعربية من اليمين:** الأوامر والمسارات والروابط في أسطر مستقلة داخل
  كتل كود، ولا جملة عربية مخلوطة بعبارة إنجليزية طويلة.
- **الخلاصة أولاً** ثم التفصيل. والخطوات مرقّمة.
- **لا مجاملة.** صحّح المقدّمة الخاطئة قبل البناء عليها.
- **التوصية مع كل قرار**، لا خيارين ليختار بينهما.
- **ما يُسلَّم له بسيط ومختصر.** التفاصيل مكانها المستودع.
