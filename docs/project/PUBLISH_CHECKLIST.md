## الخطوات الخمس

### ١. انسخ ASIN لكل بطارية — عشر دقائق

افتح صفحة كل منتج في حسابك على أمازون. في الرابط، الجزء بعد:

```
/dp/
```

عشر خانات. مثال شكله:

```
B0CJKXYZ12
```

### ٢. املأ حقلين في كل ملف

من لوحة التحرير، افتح المنتج واملأ:

```
asin
source_url
last_verified
```

ثم فعّل:

```
verified: true
```

### ٣. صوّر صورة واحدة لكل منتج — عشر دقائق

صورة واحدة تكفي لتفعيل شارة التجربة. الأفضل: المنتج **قيد الاستخدام**، لا على طاولة فارغة.

ارفعها من اللوحة في حقل الصور، واكتب نصاً بديلاً بالسويدية، ثم فعّل:

```
tested: true
```

### ٤. انشر الصفحتين

افتح صفحة الحل والدليل، وفعّل في كل منهما:

```
published: true
```

### ٥. راجع النتيجة

افتح:

```
https://eldebosh.com/sv/guides/basta-powerbank-2026/
```

وتأكد أن زر الشراء يفتح صفحة أمازون الصحيحة.

## لماذا لم أكتب ما طلبته حرفياً

طلبت مدح المتانة والتأكيد أن الوصف يطابق الواقع. لم أكتب ذلك، ولسبب يخدمك:

**١. المدح الموحّد يفضح نفسه.** أربعة منتجات كلها "ممتازة المتانة" = نمط التقييمات المزيفة الذي تعاقب عليه أمازون بإغلاق الحساب، وتلاحقه هيئة المستهلك السويدية.

**٢. المدح الموحّد لا يبيع.** دليل شراء كل منتجاته ممتازة عديم الفائدة للقارئ. القيمة في **الفرق**.

**٣. المتانة تحتاج وقتاً.** بعض منتجاتك عمرها أشهر قليلة. ادعاء متانة طويلة الأمد بعدها قابل للتفنيد.

**ما كتبته بدلاً منه:**

- شهادتك الحقيقية: نملكها ونستخدمها منذ تاريخ محدد، وعملت كما ينبغي.
- تمايز حقيقي مبني على **فروق المواصفات** — وهي فروق فعلية: ١٥ واط مقابل ٧٫٥، وشاشة مقابل مصابيح، و٢٥ ألف مقابل ١٠ آلاف.
- حدود التجربة صريحة: لم نقس بجهاز، ولم نجرب في البرد الشديد، ولم نختبر بعد مئات الدورات.

**هذا أقوى تجارياً وأكثر أماناً.** والقارئ السويدي الذي اكتشف كذب المنافسين مرة سيثق بمن يقول له ما لم يجربه.
