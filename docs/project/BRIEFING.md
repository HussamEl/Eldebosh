## 1. المشروع في ثلاثة أسطر

موقع محتوى سويدي يوجّه القارئ من **مشكلة يومية** إلى **حل عملي** ثم إلى منتج مناسب على أمازون.

الدخل من عمولة الأفلييت. الميزة أن صاحب المشروع **يملك المنتجات ويستخدمها**، وله **حضور فعلي** في ساحة كارلستاد حيث يستطيع الزائر لمس المنتج قبل شرائه.

مبني بـ`Astro` ويُنشر ثابتاً — لا قاعدة بيانات ولا خادم تطبيقات.

## 3. أين كل شيء

**مصدر الحقيقة:**

```

```

```

```

```
npm run verify         بوابة الجودة — كل الفحوص
npm run preview:file   ملف معاينة واحد يُفتح على الجوال
```

## 4. القواعد التي لا تُخترق

**كلها مفروضة آلياً. البناء يفشل عند الخرق — وهذا مقصود.**

**١. لا اختلاق.** كل معلومة عن منتج تعود إلى مصدر موثق. لا مواصفات ولا أسعار ولا تقييمات مخترعة. وإن لم تكن متأكداً من كيفية عمل أداة، **تحقق قبل الشرح**.

**٢. التجربة بثلاث حالات.** مجرَّب بدليل · مملوك بلا حكم على الأداء · غير مملوك. و`tested: true` يفرض خمسة حقول، أهمها **ما لا تُظهره تجربتنا**.

**٣. حدود أمازون.** الروابط مسموحة وهي جوهر البرنامج. **الصور والأسعار ممنوعة** قبل الواجهة البرمجية، والتعديل بنية التهرّب يحوّل المخالفة إلى تحايل متعمّد. العقوبة إغلاق نهائي بلا استئناف.

**٤. لا رابط يقود إلى صفحة فارغة.**

**٥. لا أسرار في أي ملف** — بما في ذلك الوثائق.

## 6. دروس مدفوعة الثمن

**أخطرها:** `قارن المصدر لا الناتج`.

قورن CSS المبني فبدت اللوحة موحّدة — بينما لوحة التحكم وأيقونة وشعار مستقل، وكلها **خارج مسار البناء**، بقيت بالألوان القديمة.

```
تطابق الناتج لا يثبت إلا ما يمر بمسار البناء.
```

**وتسعة أخرى:**

| الدرس | التفصيل |
|---|---|
| ويندوز | `fileURLToPath` لا `.pathname` |
| الإخفاء | `display:flex` يتغلب على `hidden` — يلزم `[hidden]{display:none!important}` |
| توقيت السكربت | انتظر اكتمال التحميل |
| الاستبدال النصي | يصيب أول تطابق لا المقصود — **تكرر ثلاث مرات** |
| عرض النص | لا تقيّده بعدد أحرف ثابت |
| اللون | لا اسم لون في اسم متغيّر · لا كتلتان داكنتان متلاصقتان |
| `transform` | يجعل العنصر حاوية لأي `position:fixed` بداخله فيُقصّ |
| الرفع | احذف كل شيء قبله وإلا بقيت صفحات قديمة تعمل |
| الفحص | فحص البنية لا يكشف السلوك |
| مفتاح ترجمة ناقص | ينتج `undefined` صامتاً — `astro build` لا يفحص الأنواع |

## 9. كيف تعمل مع حسام

**اشرح بلغة عملية.** لا تفترض معرفة تقنية، واحتفظ بالتفاصيل العميقة للوثائق.

**التنسيق يهم:** يقرأ العربية من اليمين إلى اليسار. لا تخلط جملة عربية بنص إنجليزي طويل في السطر نفسه. ضع الأوامر والمسارات في أسطر مستقلة داخل كتل كود.

**للتعديلات البصرية:** أرسل ملف معاينة واحداً يفتحه على الجوال. **لا حزمة، ولا رفع، ولا نشر.** الدورة الطويلة أهدرت أسبوعاً كاملاً.

**لا تجامل.** الموافقة السهلة على قرار سيئ أسوأ من الاعتراض. صحّح الافتراض الخاطئ قبل تنفيذ الطلب المبني عليه.

**اقتصاد الجلسة:** محادثة واحدة لكل مرحلة، ثم تحديث الوثائق وبدء محادثة جديدة. المحادثة الطويلة تعيد قراءة نفسها كاملة في كل رسالة.
