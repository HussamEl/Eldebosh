# رفع الموقع إلى Hostinger — v1.0

## القاعدة الوحيدة

**احذف كل شيء قبل الرفع.**

الرفع فوق ملفات قديمة **يستبدل الموجود ويترك ما لم يعد يُولَّد**. الصفحات القديمة تبقى على الخادم بتصميمها القديم، ويصل إليها الزائر من القوائم القديمة.

## الخطوات

**١.** افتح مدير الملفات في Hostinger، ثم:

```
/public_html/
```

**٢.** حدّد كل شيء بداخله واحذفه. **بلا استثناء.**

**٣.** ارفع محتويات الملف المضغوط — المحتويات نفسها، لا المجلد.

**٤.** افتح الموقع بـ:

```
Ctrl + Shift + R
```

## كيف تتأكد أن النسخة الجديدة تعمل

اضغط على الصفحة بالزر الأيمن ثم:

```
View page source
```

وابحث عن:

```
eldebosh-build
```

بجانبه تاريخ البناء ووقته. **إن كان قديماً، فالخادم يعرض نسخة قديمة.**

## علامة ثانية

في مجلد `_astro` يجب أن يوجد **ملف تنسيق واحد فقط**. وجود أكثر من ملف `.css` يعني أن الحذف لم يكتمل.

## قائمة المجلدات الصحيحة

انظر `SERVER_FILES.md` — فيه كل مجلد يجب أن يوجد بعد الرفع. **أي مجلد آخر بقايا قديمة.**
