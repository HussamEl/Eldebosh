## 6. مخطط المنتج

```yaml
id, code            # code رمز ثابت P-NN — أسماء الصور مبنية عليه
name, brand, category, subcategory
key_specs: {}       # أول مواصفة رقمية = الرقم البطل في البطاقة
pros, cons, best_for
price_band          # budget | mid | premium
asin                # المُدخل الوحيد للأفلييت — الرابط يُولَّد
source_url, last_verified
owned, tested, owned_since, usage_period
own_photos          # حد أقصى 3 — {src, alt, caption}
hands_on, hands_on_limits
verified            # بوابة الظهور
```

**قاعدة الوسوم:** `best-overall` وأخواتها توضع على **علاقة المنتج بالدليل**، لا على المنتج. نفس المنتج قد يكون الأفضل قيمة في دليل وغير مناسب في آخر.

**بوابة الظهور:** `published` للمحتوى في `docs()` · `verified` للمنتجات في `getProduct()` و`verifiedProducts()`. **واستثناء مقصود:** منتج مملوك بصورة من تصويرنا يظهر بلا زر شراء وبعلامة `Länk kommer`.

**خط الإنتاج:** `draft → written → reviewed → published`. الفحص يرفض التناقض مع `published`.

**تسمية الصور:** `P-NN-K.webp` — والأولى تحمل `ASIN` إن وُجد. من صورة إلى ثلاث لكل منتج، تتبدّل تلقائياً بـCSS.

## 10. النشر — يدوي بقرار حسام

**القرار النهائي:** `Claude Code` يدفع إلى GitHub، وحسام يرفع محتويات `site/`
يدوياً إلى Hostinger. **لا نشر آلي، ولا انتقال إلى استضافة أخرى.**

**لماذا لم يُؤتمت:** الرفع عبر FTP من GitHub Actions يسقط بـ`Timeout (control
socket)` — الاستضافة تحجب خوادم GitHub. البديل كان نقل الاستضافة إلى واحدة
**تسحب** من المستودع، **ورفض حسام النقل**. وworkflows الـFTP حُذفت لأنها كانت
ستفشل عند كل دفعة.

| الدليل الذي جُمع | ما يعنيه |
|---|---|
| البناء ينجح دائماً | المشكلة ليست في الكود |
| المحاولتان تنتهيان بـ`2m 0s` بالضبط | المهلة كاملة — الاتصال لم يُفتح |
| `Timeout (control socket)` | لم يصل إلى مرحلة كلمة المرور |

**⚠️ الأثر الذي يجب أن يبقى واضحاً:** لوحة التحرير تكتب في المستودع لا في الموقع.
بعد كل تحرير من `/admin/`: اسحب، ابنِ، ارفع.

**نسخة الأمان:** المستودع على GitHub — المصدر والناتج والهوية والوثائق كلها فيه.
الخطر R-06 مغلق ما دام الدفع يعمل.

**القرار مفتوح لإعادة النظر** إن أرهق الرفع اليدوي: استضافة تسحب تلغي الخطوة كلها.
