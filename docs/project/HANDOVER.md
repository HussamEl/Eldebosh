## 1. ما هو المشروع

`eldebosh.com` — موقع محتوى سويدي عن **الشحن والكابلات والحوامل**.

يأخذ القارئ من **مشكلة يومية** («الجوال يفصل قبل المساء») إلى **حلّ عملي** ثم
إلى **منتج مناسب**. وليس متجراً، ولا موقع أخبار تقنية.

| البند | القيمة |
|---|---|
| الدخل | **Affiliate حصراً** — Amazon Associates، الوسم `electro066-21` على `amazon.se` |
| السوق | السويد |
| اللغات | `sv` لغة المحتوى · `en` واجهة كاملة بمحتوى غير مترجم بعد |
| الاستضافة | Hostinger · `eldebosh.com` مع `SSL` |
| المستودع | `github.com/HussamEl/Eldebosh` — **عام** |

**الميزة التي يقوم عليها المشروع كله:** صاحب المشروع **يملك المنتجات فعلاً
ويصوّرها بنفسه**. لا صورة من متجر، ولا «الأفضل في الاختبار»، ولا رقم بلا مصدر.
وهذه ليست نبرة تسويقية — **هي مفروضة آلياً في `scripts/validate.mjs`، والبناء
يسقط عند المخالفة.**

**والثوابت التي لا تغيّرها الأرقام:**

- **الاختناق تحريريّ لا تقنيّ.** كل منتج موثَّق له مصدر مسمّى منذ إغلاق
  `I-019`. وما يحجب الأدلة هو `pros` و`cons` و`best_for` ونصّ الدليل — وهو عمل

| الحقل | يجيب عن |
|---|---|

صراحةً إنه لم يُكتب بعد. **قرارُ مالك، لا سهو** — `I-020`.

| `brand/` | الهوية ومولّداتها — كل أصل يُعاد توليده من `brand/src/` |

| `docs/project/` | **الوثائق الحاكمة والسجلات** |

| `site/` | **مخرَج البناء، مدفوع في المستودع عن قصد** — لا يُحرَّر يدوياً |
| `csv/` | جداول المنتجات والصور، مولَّدة، لخانة `Context` عند الأطراف الأخرى |

### الفروع

```
main     المصدر + site/          ← كل العمل هنا
deploy   محتويات site/ في الجذر  ← تسحب الاستضافة منه · لا يُحرَّر بيد
```

### النشر — تلقائي بالكامل

```
دفعة إلى main → GitHub Actions يبني ويفحص → يحدّث فرع deploy
              → Webhook يوقظ الاستضافة → تسحب إلى public_html
```

**لا `FTP` ولا أسرار ولا خطوة يدوية.** والاتجاه معكوس عمداً: خوادم غيتهب محجوبة
عن الدخول إلى الاستضافة، فالاستضافة هي التي تخرج وتأخذ. التفصيل في
`docs/12-deploy-from-github.md`.

**وكيف تتأكد أن النشر جرى:** بجانب زر الهوم على الموقع **ختمُ بناء** يساوي وقت
البناء. ساواه ← وصل. (أداة مؤقتة تُحذف قبل الإطلاق — `T7` في `TASKS.md`.)

**وإن تعطّل النشر التلقائي يوماً:** خطّ الرجعة اليدوي في `docs/project/UPLOAD.md`
و`docs/05-deployment.md`. **اقرأهما قبل أي رفع يدوي** — الرفع فوق القديم كسر
الموقع ثلاث مرات.

## 4. كيف تشتغل عليه


**`npm run verify` هو المعيار الوحيد.** لا يُدفع شيء وهو أحمر، ولا تُعدّ مهمة
منجزة وهو أحمر. وفي غيتهب يُضاف إليه فحص خامس عشر: `check:drift`.

### ما تفحصه البوابة، ولماذا بُني كل واحد

| الفحص | يمنع |
|---|---|
| `validate.mjs` | القواعد الملزمة كلها — كل كتلة قواعد فيه من عطب وقع فعلاً |
| `test:claims` | ٣٢ حالة اختبار لقاعدة الادعاء — نصٌّ يدّعي تجربة أو عدداً بلا بيانات تسنده |

| `check:colors` | لون خارج نظام التصميم |
| `check:docs` | رقم رسالة أو إصدار وثيقة غير متّسق |

**ولا يُضاف فحص إلا بعد عطب وقع.** كل واحد مكتوب في رأسه أيّ عطب أنتجه.

## 4b. ضجيج معروف — لا تُبلّغ عنه ولا تسأل حسام فيه

**ثلاثة أشياء ستراها في أول ساعة، وكلّها متوقَّعة ومحسومة.** حُصرت هنا لأن جلسة
جديدة اصطدمت بها ورفعتها إلى حسام كقرارات — وليست قرارات (`I-022`).

### ١. `verify` يجعل الشجرة «متّسخة» في كل مرة

بعد أي `npm run verify` — **ولو لم تحرّر حرفاً** — تجد عشرات الملفات معدّلة،
سطراً واحداً في كلٍّ منها: **ختم البناء**، أي `<meta name="eldebosh-build">`.
البناء يكتب فيه وقته فيتغيّر الوقت. **لا محتوى ولا مواصفة ولا صفحة.**

**والضجيج محصور في ثلاثة مواضع بالضبط:**

```
site/
docs/project/STATE.md
docs/project/SERVER_FILES.md
```

**فالتراجع يكون مُوجَّهاً إليها وحدها:**

```
git restore site/ docs/project/STATE.md docs/project/SERVER_FILES.md
```

> **⚠️ ولا تكتب `git restore .` أبداً.** يمحو **كل** تعديل غير مودَع بما فيه
> عملك أنت. وهذا ليس تحذيراً نظرياً: كُتب هذا القسم أول مرة ثم شُغِّل
> `git restore .` لاختباره، **فمُحيت الوثائق التي كانت تُكتب للتوّ** — سبعة
> ملفات لم تكن مودَعة.

**ولا تُودِع الضجيج ولا تدفعه ولا تسأل حسام عنه.** دفعةٌ بسبعين ملفاً من أجل
تغيّر وقت تُشعل خط النشر كاملاً وتلوّث السجل.

**وانتبه للاستثناء:** إن غيّرتَ `CSS` أو أي شيء يدخل الحزمة، فاسم ملف الحزمة
يتغيّر وتتغيّر معه كل صفحات `site/` تغييراً **حقيقياً** — تلك تُودَع كاملة.
افحص الفرق قبل أن تحكم: إن كان فيه اسم ملف `_astro/*.css` جديد فهو عمل، لا ضجيج.

*(ولماذا لا يكسر هذا البوابة على غيتهب: `check:drift` **يقنّع الختم** فلا يحسبه
انحرافاً.)*

### ٢. تنبيهان في `npm run check` — كلاهما معروف ومقرَّر

**التنبيه ليس خطأً.** البوابة خضراء، وفيها اثنان فقط، وكلاهما «نصّ التجربة
مكرّر حرفياً» بين `P-01` و`P-04` و`P-11`.

**قرار حسام: يُتركان.** سيعيد كتابة النصوص بنفسه، وهو وحده من يملك ذلك — لأن
نصّ التجربة ادعاءٌ عن شيء استعمله هو. **فلا تُعِدهما كاكتشاف، ولا تحاول
إصلاحهما.**

### ٣. الفرع الذي تدفع إليه — `main` وحده

**العمل على `main` والدفع إليه مباشرة.** ولو فرضت بيئةُ تشغيلك فرعاً باسم
الجلسة — وهي تفعل ذلك عند فتح الجلسة من الويب — **فاعمل فيه، ثم ادمجه إلى
`main` وادفعه واحذف الفرع، في الجلسة نفسها.**

**قرار حسام في `2026-09-05` — `D-028`:** الفرع الموازي يترك نسختين من العمل
ودورة دمج إضافية بلا مراجِع بشري ينتظرها. والإذن الصريح مكتوب في `CLAUDE.md`
حيث تقرؤه كل جلسة قبل أي ملف آخر.

**والحارس هو الفحص لا الفرع.** ولا `Pull Request` إلا بطلب حسام صراحةً.

**وقل له في أول رد أين تدفع** إن كانت بيئتك فتحت فرعاً. هذه الجملة وحدها هي ما
كان ناقصاً في المرة التي انتهت بعمل لم يظهر على الموقع.

## 6. الأطراف وآلية التواصل

أربعة أطراف لا يتصل بعضها ببعض. **حسام هو القناة الوحيدة** — ينسخ ويلصق.

| الطرف | يفعل | لا يفعل |
|---|---|---|
| **حسام** | يملك · يقرّر · يصوّر · ينقل الرسائل | **ليس مبرمجاً** |
| **Claude Project** | المواصفات · المحتوى · `SEO` · التحرير | **لا يدفع إلى غيتهب إطلاقاً** |
| **Claude Code** | المستودع · التنفيذ · الفحوص · النشر | لا يقرّر تحريراً |
| **Gemini** | بحث خارجي عند الطلب | لا ينفّذ في الكود |

### الترقيم — إلزامي

كل رسالة تفتح بسطر واحد:

```
EB-004 · Claude Code · 2026-09-05 13:25 · رداً على EB-003
```

عدّاد **واحد لكل الأطراف**، وتوقيت **كارلستاد** يُقرأ من الساعة لا يُقدَّر.
والرقم التالي والوقت الصحيح يطبعهما:

```
npm run check:docs
```

### وكل رد يُختم بلوحة الأطراف

```
| | الطرف | الحالة |
|---|---|---|
| ✍️ | كلاودي كود | كتب هذا الرد · EB-004 |
| 🔴 | كلاودي بروجيكت | مطلوب: <إجراء واحد> |
| 💤 | جيميناي | لا شيء ينتظره |
| ✅ | حسام | لا شيء مطلوب |
```

`✍️` كتب · `⏳` ينتظر · `🔴` عليه عمل الآن · `🟡` يمكن أن ينتظر · `💤` غير معنيّ
· `✅` أنجز. **وكل طرف يظهر في كل مرة** — غيابُ طرف من اللوحة هو ما أضاع الخيط
سابقاً.

**وتحت اللوحة سطر واحد** يقول أي نسخ من الوثائق الحاكمة أُرسلت إلى حسام آخر
مرة. **يُقرأ من `npm run check:docs`، لا من الذاكرة.**

### الخلل المعروف في الآلية

**رسائل تضيع.** `Claude Project` يكتب في محادثته ولا يملك وسيلة دفع، فما لا
ينقله حسام **لا وجود له**. ضاعت رسالتان هكذا ومعهما ملفا منتجين وصفحة كاملة،
فظهرت فجوة في ترقيم المنتجات كشفت المشكلة.

**والعلاج المطبَّق:** كل ما يصل يُودَع في المستودع في الدفعة نفسها، ويُسجَّل في

## 7. كيف تتعامل مع حسام

هذه ليست آداباً، بل شروط عمل قالها بنفسه:

- **ليس مبرمجاً.** اشرح بلغة عملية، ولا تطلب منه أوامر طرفية إلا للضرورة.
- **يقرأ بالعربية من اليمين.** ضع الأوامر والمسارات في **أسطر مستقلة داخل كتل
  كود**، ولا تخلط جملة عربية بعبارة إنجليزية طويلة في سطر واحد.
- **لا تجامله.** الموافقة السهلة على قرار خاطئ أسوأ من الاعتراض. صحّح المقدّمة
  الخاطئة قبل أن تنفّذ ما بُني عليها.
- **الضجيج التقني ليس قراره.** `git` والفروع والبناء والتنسيق تحسمها أنت
  وتخبره بجملة إن كانت تستحق.
- **وقراره هو:** المال · ما يراه الزائر · وعدٌ يُقطع باسم الموقع · حساب أمازون
