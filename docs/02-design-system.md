# نظام التصميم

كل القيم معرّفة كمتغيّرات CSS في `:root` داخل `site/_astro/site.v2.css`.
لا تكتب لونًا مباشرًا في أي قاعدة — استخدم الرمز.

## الألوان

| الرمز | القيمة | الاستخدام |
|---|---|---|
| `--ink` | `#10161D` | نص المتن |
| `--ink-2` | `#3F4C59` | نص ثانوي |
| `--muted` | `#66727F` | تسميات، شعار فرعي، عدّادات |
| `--paper` | `#FFFFFF` | البطاقات |
| `--page` | `#E7F2FD` | خلفية الصفحة |
| `--mist` / `--mist-2` | `#F2F7FC` / `#E4EEF7` | خلفيات خفيفة |
| `--line` / `--line-2` | `#D7E3EE` / `#BCD2E3` | حدود وفواصل |
| `--brand` | `#1273D1` | الروابط، الأزرار، الشرائح المفعّلة |
| `--brand-deep` | `#123F66` | الترويسة والفوتر |
| `--brand-hero` | `#14456E` | بداية تدرّج الهيرو |
| `--brand-soft` / `--brand-tint` | `#F0F7FE` / `#D3E7FA` | أسطح ملوّنة خفيفة |
| `--volt` | `#55C6F2` | لون التمييز (شريط الشحن، زر البحث) |
| `--volt-deep` | `#2FB2E6` | حالة hover للون التمييز |
| `--warn` | `#8A4B1F` | حالة «لا نتائج» |

**قاعدة تباين:** `--volt` لون تمييز لا لون نص. لا تكتب به نصًا صغيرًا على أبيض.

## الخطوط

| الرمز | العائلة | أين |
|---|---|---|
| `--font-display` | Inter Tight Var | العناوين، الكلمة، الأرقام الكبيرة |
| `--font-body` | Inter Var | كل ما عدا ذلك |

سلّم المقاسات `--step--2` … `--step-4` مبني على `clamp()`، فالحجم يتدرّج مع عرض
الشاشة دون نقاط انكسار. لا تكتب `font-size` بقيمة ثابتة خارج هذا السلّم.

## المسافات والأشكال

| الرمز | القيمة |
|---|---|
| `--gap` | `clamp(.85rem, .65rem + .9vw, 1.35rem)` |
| `--section` | `clamp(2.5rem, 1.7rem + 3.2vw, 4.5rem)` |
| `--wrap` / `--wrap-text` | `78rem` / `44rem` |
| `--r-sm` / `--r` / `--r-lg` | `8px` / `12px` / `18px` |
| `--head-h` | `58px` — ارتفاع الترويسة اللاصقة |

## المكوّنات الأساسية

| المكوّن | ملاحظات |
|---|---|
| `.charge` | شريط الشحن: مسار رمادي + تعبئة `--volt` بنسبة `--fill`. الموتيف نفسه في الشعار. |
| `.tile` | بطاقة منتج. `overflow:hidden` + `transform` عند المرور — لا تضع فيها عنصرًا `position:fixed`. |
| `.tile-photos` | كومة صور تتلاشى تلقائيًا؛ عند المرور تتوقف على الصورة الأولى. |
| `.viewer` | نافذة الصور. تُنقل إلى `<body>` بجافاسكربت، وتعمل بـ`:target` بدونه. |
| `.chip` | شريحة فلترة؛ `.is-on` تعني مفعّلة، مع `aria-pressed`. |
| `.brand img` | الشعار في الترويسة، ارتفاع ثابت 26px (23px تحت 22em). |

## قواعد عامة

- كل تأثيرات المرور داخل `@media(hover:hover)` حتى لا تعلق على شاشات اللمس.
- `prefers-reduced-motion` يوقف الأنيميشن ويُظهر الصورة الأولى فقط.
- الحد الأدنى لمساحة اللمس 44px على الأجهزة اللمسية (`@media(pointer:coarse)`).
- `:focus-visible` يرسم إطارًا واضحًا — لا تحذفه.
