# الهوية

الدليل الكامل للاستخدام (النسخ، مساحة الحماية، الألوان، المطبوعات) في
[`../brand/GUIDELINES.md`](../brand/GUIDELINES.md). هذه الصفحة تشرح **كيف بُني**
النظام وكيف يُعاد توليده.

## الفكرة

حرف **E** من ثلاثة أعمدة مستديرة، عمودها الأوسط باللون السماوي. هذا العمود هو
`.charge` نفسه — شريط الشحن الذي يظهر فوق عناوين الموقع. الشعار ليس عنصرًا
مضافًا على التصميم، بل نفس الموتيف بحجم أكبر.

## لماذا الكلمة مسارات لا نص

`<text>` في SVG يحتاج الخط مثبّتًا عند العارض؛ وإن غاب استبدله المتصفح بخط آخر
وتغيّر الشعار. المولّد يستخرج مسارات الحروف من خط Inter Tight المتغيّر الموجود
في `site/fonts/`، بعد تثبيته عند وزن 800، ويمرّرها عبر HarfBuzz لضبط التقنين
والتباعد. الناتج ملف مستقل تمامًا: يفتح متطابقًا في أي برنامج ومطبعة.

## خط الإنتاج

```
brand/src/typeset.py     الخط -> مسارات SVG (fontTools + uharfbuzz)
brand/src/build_logo.py  يبني كل نسخ الشعار      -> brand/logo/
brand/src/assets.py      دُكوك السوشال كـHTML     -> brand/src/build/canvas/
brand/src/print.py       دُكوك المطبوعات كـHTML   -> brand/src/build/canvas/
brand/src/render.mjs     يصوّر الدُكوك والشعارات   -> brand/social/ logo-png/ icons/
brand/src/print.mjs      يطبع الدُكوك إلى PDF     -> brand/print/
```

### إعادة البناء

```bash
pip install -r brand/src/requirements.txt
npm install                 # Playwright
npm run brand:all           # الأوامر الستة أعلاه بالترتيب
```

المخرجات حتمية: إعادة التشغيل تنتج نفس البايتات في SVG و PNG. ملفات PDF وحدها
تختلف لأنها تحمل طابع وقت الإنشاء.

### تعديل الألوان

القاموسان `BLUE` و`GREEN` في أعلى `build_logo.py`. غيّر القيمة وأعد `brand:all`.

### تعديل الشعار الفرعي أو الاسم

الثوابت `CAP`، `TRACK`، `TAG_SIZE`، `TAG_TRACK` في `build_logo.py` تتحكم بارتفاع
الحروف والتباعد. النص نفسه في دوال `_tag_row` و`_words`.

## فخّ تقني يستحق التذكّر

`<rect rx="...">` في SVG: إن كان `rx` أكبر من نصف العرض، يقصّه المتصفح إلى نصف
العرض **لكنه يُبقي `ry` على القيمة الأصلية**، فتتحوّل الزوايا إلى أقواس بيضوية.
العمود الرأسي للحرف كان يُرسم هكذا ويبدو منتفخًا. القاعدة:
`rx = min(width, height) / 2`.
