# النشر — يدوي بقرار صاحب المشروع

**القرار:** أنا (`Claude Code`) أدفع إلى GitHub، وحسام يرفع الملفات يدويًا إلى
Hostinger. لا نشر آلي، ولا FTP من GitHub Actions.

**لماذا:** الرفع الآلي عبر FTP يسقط بـ`Timeout (control socket)` — الاستضافة تحجب
خوادم GitHub. والبديل الآلي يعني نقل الاستضافة، وحسام اختار البقاء عليها.
وworkflows الـFTP حُذفت لأنها كانت ستفشل عند كل دفعة.

---

## ⚠️ القاعدة التي تسبق كل شيء

**احذف كل محتويات `public_html` قبل الرفع.**

الرفع فوق القديم يترك صفحات لم تعد تُولَّد وهي تعمل بتصميمها القديم وروابطها
القديمة. هذا وقع **ثلاث مرات** في هذا المشروع.

استثناء واحد: إن كان لديك ملف لا يولّده البناء (شهادة تحقق من محرك بحث مثلاً)،
احتفظ بنسخة منه قبل الحذف وأعده بعد الرفع.

---

## الخطوات

**١. اسحب آخر نسخة**

من GitHub Desktop: زر `Fetch origin` ثم `Pull`.
أو نزّل المستودع كـZIP من صفحة GitHub.

**٢. ابنِ الموقع** (إن كنت عدّلت محتوى؛ وإلا انتقل للخطوة ٣)

```
npm install
npm run verify
```

`verify` يبني ويفحص كل شيء. **إن فشل فحص واحد، لا ترفع.**

**٣. ارفع محتويات `site/`**

من File Manager في Hostinger أو عبر FTP:

- افتح `public_html`
- **احذف كل ما فيه**
- ارفع **محتويات** مجلد `site/` — لا المجلد نفسه

**٤. تأكد أن `.htaccess` رُفع**

ملف يبدأ بنقطة، وكثير من برامج FTP تخفيه. فعّل «إظهار الملفات المخفية».
بدونه: الروابط تعمل لكن الكاش والضغط وصفحة الخطأ تتعطّل.

---

## ⚠️ لوحة التحرير تكتب في GitHub لا في الموقع

عندما تنشر شيئًا من `/admin/`، فهو يذهب إلى المستودع **فقط**. الموقع لا يتغيّر
حتى ترفع يدويًا.

**بعد كل تحرير من اللوحة:** اسحب من GitHub، ابنِ، ارفع. وإلا فاللوحة تقول
«نُشر» والموقع يعرض القديم.

---

## ماذا يفعل `.htaccess`

| القاعدة | الأثر |
|---|---|
| `DirectoryIndex index.html` | يقدّم `index.html` من كل مجلد |
| `ErrorDocument 404 /sv/` | صفحة مفقودة تعود للرئيسية السويدية |
| `mod_deflate` | ضغط HTML و CSS و JS و SVG |
| CSS/JS/woff2 | كاش سنة `immutable` — الأسماء مبصومة بالمحتوى فالتحديث يصل |
| الصور | كاش 30 يومًا |
| HTML | `max-age=0, must-revalidate` — التحديثات تظهر فورًا |
| `Options -Indexes` | يمنع تصفّح المجلدات |

الموقع لا يعتمد على WordPress. إن وُجد `.htaccess` قديم يحوّل الطلبات إلى
`index.php` فسيعطّل الموقع بالكامل — استبدله.
